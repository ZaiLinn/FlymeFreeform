# 扇形尺寸与圆形图标

扇形采用固定比例，并随当前 Overlay 窗口短边整体缩放。设置页不再提供“图标大小”和“圆角大小”。

## 尺寸规则

基准窗口短边为 400dp，圆弧半径为 242dp，图标直径为 44dp，条目单侧安全留白为 3.25dp。尺寸只由 `RadialIconGeometry` 计算，图标数量只影响排列角度。

缩放系数为 `(窗口短边像素 / density) / 400dp`，再乘当前 density 得到绘制像素。因此半径占窗口短边的 60.5%，图标占 11%；更大窗口会整体放大，同一像素窗口调整系统显示密度不会单独改变菜单占比。字体缩放不改变扇形几何。横竖屏均取当前窗口短边。

两侧各保留 3° 安全角，将剩余 84° 按实际条目数等分，并将图标放在各槽中点。六个应用加“更多”时，从底边向上依次为 9°、21°、33°、45°、57°、69°、81°。左右镜像，“更多”在最靠近底边的槽，应用保持现有顺序。

正常竖屏圆心位于物理侧边、底部导航栏上沿，不将系统手势保留区或屏幕圆角半径作为整块边距。更多应用面板保留自身的安全 Insets。外缘预算包括入场回摆和白圈留白；空间不足时所有尺寸共同缩小，不随条目数量变化。可用空间耗尽时尺寸归零且不可命中。

## 多圆弧

开启「多圆弧」后可选 1～4 条圆弧，圆弧条数由 `RadialArcPlan` 规划。第 1 条是默认圆弧，几何与单圆弧完全相同，放「数量上限」内的快捷项和「更多」。新增圆弧共用同一圆心，依次向内收拢，容量为 5、4、3 项，且每条不超过外侧一条减 1：「数量上限」调小时内圈随之收缩（例如上限 4 时为 3、2、1，上限 1 时没有内圈），不会出现外少内多的倒挂。默认圆弧放默认固定项（不足时用最近使用补位），内侧各圈按各自的固定列表或最近使用填充，目录随结果给出每圈的实际条数（`AppCatalogSnapshot.radialArcCounts`），扇形按此分圈，自定义圈放不满时空位不会挤进下一圈；内侧圆弧各自按实际条目数在 84° 内等分，「更多」只出现在默认圆弧。

相邻圆弧的半径间距在三条以内取图标直径的 1.3 倍（基准 57.2dp）；四条时整体收紧为 (242 − 2.27 × 44) / 3 ≈ 47.4dp，保证最内一条 3 个图标的圆心距仍不小于图标直径。间距随扇形整体缩放；所有内侧圆弧都在默认圆弧以内，外缘预算不变。

`RadialLayout.itemCenters` 的顺序为：默认圆弧快捷项 → 内侧圆弧快捷项（由外向内）→「更多」，下标与快捷项列表一一对应。命中仍只按「离哪个图标圆心最近」判定，内外圆弧一视同仁。有内侧圆弧时另设角落空白区：手指离圆心小于「最内一圈半径 − 一个圈距」时不选中任何条目（两条约 128、三条约 70、四条约 52 基准 dp），最内一圈因此向角落留有一个圈距的可选范围，不会被压成窄条，避免手势刚识别、手指已落进最内圈命中圈时松手误启动；单圆弧不设空白区，手感不变。命中范围预览同样画出全部圆弧。

## 命中判定

命中半径以物理 dp 表示，设置页「命中范围」可调 40～140dp，默认 140dp（本机 1272×2800、density 3.5 下即 490px，约为格间距 161px 的 3 倍）。手指到图标中心距离小于命中半径才入选；不再做弧线收边，只按最近图标判定，手指偏出弧线也能接着选。没有保持圈（保持半径 0）：换格只看「手指离哪个图标圆心最近」，两格中线处立刻切换，不做任何迟滞；早于中线就换会因为在两条规则的边界来回跳而闪烁。命中半径只是「有没有目标」的门槛，不影响换格速度。拖动滑条时浮层按同一套几何画出每个槽位的命中圈（圆弧半径 242dp、84° 扇开、3° 安全角、命中半径 = 当前 dp × density），与扇形实际绘制位置一致。

## 扇形动画与选中反馈

手势识别成功后，所有图标按时间同步展开；拖动只更新选择，不再用手指距离控制图标位置，也没有逐项延迟。

- 入场共 380ms：前 130ms 从角落展开，旋转 −270°→5°、尺寸 0.8→1.05；随后 250ms 通过旋转和横向超调曲线回摆到稳定状态。横向偏移基准为 6dp，与图标共同缩放。
- 选中/取消只改变外圈宽度：130ms、白色透明度 64/255，最宽 3.25dp，自图标外沿向外生长。选择不改变图标尺寸；全体共享的短暂入场尺寸变化仍保留。
- 扇形退场采用两段各 100ms 的旋转、位移和透明度曲线。提前松手从当前入场帧衔接退出，避免跳到展开终点。更多面板交接保留自身过渡。
- 系统关闭动画时直接落到最终状态；退出、切换面板与销毁会停止入场协程。动画值在绘制阶段读取。

## 图标与配置

自适应图标继续使用 ColorOS 独立 Drawable 的圆形塑形，保留系统图层分类和前景比例。扇形最终绘制统一使用圆形边界，普通位图及原生接口不可用的回退路径同样生效；不再次放大图案填充透明区域。“更多”保持圆形，更多应用面板保留自身的尺寸与绘制规则。

“更多”按 ColorOS 17 工具栏溢出按钮的观感自行绘制，配色分别取自该按钮浅色与深色模式的实机测量：浅色为 `#F7F7F8` 圆盘、略向下偏移的 5% 黑色柔和投影、上下沿白色高光与 `#181818` 三点；深色为自上而下 `#1F1F1F`→`#282828` 的圆盘、向下偏移的 8% 白色微光、12% 白色上下沿高光与 `#E9E9E9` 三点。三点横排。深浅色只在 `CornerOverlayTheme` 解析一次，扇形配色经 `LocalRadialItemColors` 读取。三点比例沿用该按钮 40dp 圆盘内 24dp 图标的实机测量，随扇形图标直径缩放；不打包系统图标或其他 ColorOS 资源。

应用图标裁成圆形后叠加物理 1px、14% 透明度（`#24FFFFFF`）的白色内描边，使深色图标在半透明遮罩上保有清晰边缘。浅色模式不压暗，避免图标发灰；深色模式另叠 12% 透明度（`#1F000000`）的黑色压暗层，避免在黑色遮罩上刺眼。“更多”不叠加这些层。

分身应用的图标与角标分层传输：侧边栏进程发送不带角标的图标，并让系统在同尺寸透明底图上绘制分身用户角标。扇形先按圆形裁剪图标，再把角标不裁剪地叠在图标外接正方形上，并盖在选中外圈之上。右侧扇形保留角标的右下角位置；左侧扇形按角标可见范围平移到对称的左下角，避开相邻图标，角标本身不翻转。可见范围在目录工作线程计算，绘制时随图标尺寸缩放。包内只有一个启动入口时，分身复用主用户的自适应图标，与普通应用同样进行原生圆形塑形。设置页列表同样将角标叠在裁剪后的图标之上，保留右下角位置。

已停止读取、写入大小、圆角以及更早的图案缩放与圆形开关配置。旧键保留在存储中但不再生效，也不复用；用户无需手动恢复默认值。目录结果仍须匹配当前固定应用选择才能发布。

## 验证边界

纯逻辑测试覆盖基准尺寸、分辨率和密度换算、横竖屏、1～7 个条目、左右安全区、空间不足、白圈间距、入退场曲线和旧键失效。构建与测试不能替代 ColorOS 真机上的最终视觉、圆形边缘及滑选验证。
